# Project Context: Limo & Black Car Service App

## App Overview
- **Purpose:** Web application for a premium limo and black car transportation business.
- **Goal:** Provide a high-end, stunning user experience for clients booking rides.

## Design Aesthetic (CRITICAL)
- **Vibe:** Premium, luxury, dark mode.
- **Colors:** Deep blacks, charcoal greys, and premium accent colors (e.g., gold, silver, deep blue).
- **Styling:** Glassmorphism, smooth micro-animations, and modern typography (e.g., Inter, Outfit).
- **Quality:** Do NOT use generic UI. Needs to feel incredibly high-end.

## Tech Stack
- **Framework:** Next.js (App Router, initialized with React, TypeScript).
- **Styling:** Tailwind CSS (installed by default) / Vanilla CSS modules. Ensure any UI looks strictly bespoke.

## Core Features
- **Hero Section:** High-impact landing area.
- **Fleet Presentation:** Showcase available vehicles (Sedans, SUVs, Sprinters).
- **Booking Flow:** Sleek, user-friendly booking/contact form.
